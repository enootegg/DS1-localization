# Українізатор Death Stranding

Українська локалізація **DEATH STRANDING** і **DEATH STRANDING DIRECTOR'S CUT** для ПК.
Текст, шрифти й текстури з написами — усе українською.

Встановлення — це два файли, скопійовані в теку з грою. Нічого не треба запускати, файли самої
гри не змінюються, а щоб прибрати переклад, досить ці два файли видалити.

Для вас переклали: **[Спільнота Єнота](https://t.me/spilnota_enota)**.

## Встановлення

1. Завантажте архів для свого видання гри зі сторінки [релізів](../../releases/latest):

   | Ваша гра | Архів |
   |---|---|
   | DEATH STRANDING DIRECTOR'S CUT | `Death.Stranding.Directors.Cut.UA.<версія>.zip` |
   | DEATH STRANDING (звичайна) | `Death.Stranding.UA.<версія>.zip` |

2. Розпакуйте його вміст у теку з грою — туди, де лежить `ds.exe` або `DeathStranding.exe`.
   Має вийти так:

   ```
   <тека гри>\
   ├── ds.exe
   ├── winhttp.dll              ← новий файл
   └── localization\
       └── ds_ua.bin            ← новий файл
   ```

3. Запустіть гру.

> **Архіви не взаємозамінні.** Архів для Director's Cut не підходить до звичайної гри, і
> навпаки — гра може не запуститись.

Якщо раніше ви ставили українізацію старим інсталятором, спершу видаліть її тим самим
інсталятором, щоб гра повернулась до початкового стану.

**Видалення.** Видаліть `winhttp.dll` і теку `localization` з теки гри.

**Оновлення.** Розпакуйте новий архів поверх старого.

| Гра | Магазин | Стан |
|---|---|---|
| DEATH STRANDING DIRECTOR'S CUT | Steam | ✅ перевірено |
| DEATH STRANDING | Epic Games | ✅ перевірено |
| DEATH STRANDING DIRECTOR'S CUT | Epic Games | ❔ не перевірялось |
| DEATH STRANDING | Steam | ❔ не перевірялось |

| будь-яка | Linux / Steam Deck | ❔ не перевірялось |

Неперевірені варіанти — це та сама гра з іншого магазину, яку в нас не було змоги запустити.
Якщо українізатор її не впізнає, гра просто запуститься англійською. Якщо ви спробували —
розкажіть, як пройшло.

## Якщо переклад не з'явився

Після запуску поруч із файлом гри з'являється `ds1_localizer.log`. Відкрийте його Блокнотом:

| Що в файлі | Що це означає | Що робити |
|---|---|---|
| `Mounted source:localization/ds_ua.bin` | Усе працює | — |
| Файлу немає взагалі | Гра не побачила `winhttp.dll` | Перевірте, що він лежить поруч з exe гри |
| Є лише рядок `Hooked…` | Немає архіву з перекладом | Перевірте теку `localization` і файл `ds_ua.bin` у ній |
| `expected 1 signature match` | У вас інша версія гри, ніж перевірені | Напишіть нам, вказавши магазин і версію гри |
| `FAILED to mount` | Архів пошкоджений | Завантажте його ще раз |

Якщо гра вилітає одразу після встановлення — найімовірніше, архів не від вашого видання.

## Як це працює

Гра зберігає текст, шрифти й зображення у великих архівах і вміє накладати їх один на один:
якщо той самий файл є у двох архівах, вона бере його з того, що підключений останнім. Так
розробники випускають власні патчі — і так само працює українізатор:

- **`localization\ds_ua.bin`** — невеликий архів, у якому лежать тільки перекладені файли.
- **`winhttp.dll`** — помічник, який гра підхоплює під час запуску. Він робить одну річ:
  просить гру підключити цей архів останнім, поверх її власних.

Далі гра працює як завжди — просто, шукаючи файл, спершу знаходить український. Оригінальні
архіви ніхто не чіпає, і переклад зникає безслідно, щойно видалити два файли.
